# Security policy

## Supported versions

Security fixes are provided for the latest published FastTube release. Users are
encouraged to update through the application's updater or GitHub Releases.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow on the repository's Security
tab. If private reporting is unavailable, contact the maintainer through the
GitHub profile listed in the repository metadata. Include a concise reproduction,
affected version, and impact.

Do not include OAuth tokens, cookies, API credentials, raw error messages,
private URLs, or local filesystem paths in a public issue. Rotate any credential
that may have been exposed before reporting the issue.
